# Kurarium 0.5.1 パブリックベータ

Kurarium 0.5.1は、0.5.0パブリックベータの更新版です。Windows向けバイナリは**コード署名されていません**。実行前に、公開されているSHA-256チェックサムを確認してください。

## 主な変更

- すべてのライブラリを無効化・有効化・削除できるようにしました。旧設定から作成された既定ライブラリも対象です。
- 新しく追加したライブラリが既定扱いになり、削除できなくなる不具合を修正しました。
- 設定画面のタブ名を、自由入力に対応したコンボボックスに変更しました。入力中も標準タブ（画像・動画・PDF・音楽）をすべて選択できます。
- ライブラリ削除の確認をWeb UI内で行うように変更しました。確認は対象ライブラリの直下に表示され、ライブラリ名と「ファイルは削除されません」という注意を含みます。

## 動作環境

- Windows 11 (x64)
- 未署名インストーラー: `SHA256SUMS.txt`を確認してください。
- LANアクセス: 信頼できるローカルネットワーク専用です。インターネットへ公開しないでください。

## 既知の制限

- 非常に遅いSMBソースでは、最初のサムネイル要求がタイムアウトする場合があります。ギャラリーが再試行します。
- LAN画面は単一ユーザー向けです。認証されたすべてのクライアントが、ライブラリと設定へのフルアクセスを持ちます。
- このベータにはコード署名が含まれません。LAN用の自己署名証明書はHTTPS専用であり、インストーラーの信頼された発行元を証明するものではありません。

## 検証用ファイル

- `SHA256SUMS.txt`
- `LEGAL-NOTICES.zip`
- `FFMPEG-SOURCE.zip`
- `SBOM.cdx.json`
