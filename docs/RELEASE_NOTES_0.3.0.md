# Kurarium 0.3.0

Windows 10 22H2 / Windows 11 (x64) 向けのアップデートです。

## ダウンロード

- `Kurarium-Installer-0.3.0-win-x64.exe`: インストーラ(管理者権限不要)
- `Kurarium-Portable-0.3.0-win-x64.zip`: ポータブル版
- `SHA256SUMS.txt`: SHA-256 チェックサム
- `LEGAL-NOTICES.zip`: ライセンス全文、第三者表記、FFmpegのソース情報

## 主な変更

- サムネイルを個別ファイルから `data\thumbs.db` に移行
  - 数万ファイル → DB 1ファイル
  - ファイル管理のオーバーヘッドを削減
- サムネイルを高さ360px基準に変更
  - 横長画像・動画・パノラマの表示品質を改善
  - 最大幅1600px、WebP品質76
- 動画サムネイルをLanczos拡大縮小・品質82に改善
- 高解像度画像に軽いシャープ処理を追加
- 既存サムネイルは移行中も表示され、DB格納後に旧ファイルを自動削除
- 孤立サムネイルの削除とSQLiteのインクリメンタルバキュームに対応
- サムネイルのキャッシュバージョンを追加し、再生成後の古い表示を防止
- SMB接続の保存前にNTLMv2で接続テストを実行
  - Windows資格情報マネージャーを変更せずに認証と共有アクセスを確認
  - 成功した場合のみ接続情報を保存
  - `STATUS_LOGON_FAILURE`になるNTLMv1依存を解消
- スキャン完了後にフォルダ件数を自動更新
  - 初期設定直後に件数が0件のままになる問題を修正
- サムネイル生成中のUIカクツキを改善
  - 進捗集計をDB集計からメモリ管理へ変更
  - 毎秒の重い集計クエリを廃止
  - Sharpの並列スレッド数を抑制
  - サムネイル書き込みをDBへ集約
- 生成中のサムネイルを自動再取得し、白い・未更新の表示を改善
- 画像サイズ未取得時のライトボックスを正方形ではなく元の縦横比で表示

## データについて

初回起動時に既存サムネイルを新しい形式へ移行します。進捗は画面上部に表示されます。
ライブラリ設定・視聴履歴はそのまま引き継がれます。

- インストール版: `%LOCALAPPDATA%\Kurarium\data`
- ポータブル版: 展開先の `data`

サムネイルは `data\thumbs.db` に保存されます。バックアップ時はアプリを終了してから
`data` フォルダ全体をコピーしてください。

## 未署名について

このリリースは**コード署名されていません**。Windows SmartScreen が
「Windows によって PC が保護されました」と表示する場合があります。

SHA-256 が `SHA256SUMS.txt` と一致することを確認したうえで、
**詳細情報 > 実行** を選択してください。

```powershell
Get-FileHash .\Kurarium-Installer-0.3.0-win-x64.exe -Algorithm SHA256
```

## 既知の制限

- コード署名は未対応です。
- 自動更新はありません。
- LAN公開はHTTPです。信頼できるネットワークでのみ使用してください。
- Windows 10 22H2実機での検証は未実施です(Windows 11で検証)。
