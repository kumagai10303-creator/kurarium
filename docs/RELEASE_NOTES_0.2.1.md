# Kurarium 0.2.1

Windows 10 22H2 / Windows 11 (x64) 向けの修正リリースです。

## ダウンロード

- `Kurarium-Installer-0.2.1-win-x64.exe`: インストーラ(管理者権限不要)
- `Kurarium-Portable-0.2.1-win-x64.zip`: ポータブル版
- `SHA256SUMS.txt`: SHA-256 チェックサム
- `LEGAL-NOTICES.zip`: ライセンス全文、第三者表記、FFmpegのソース情報

## 修正内容

- LAN公開で特定のIPアドレスを待ち受けホストに指定した場合、内蔵画面が
  `127.0.0.1` に接続しようとして起動できなくなる問題を修正
  - `0.0.0.0` 指定時は従来どおり `127.0.0.1` で開きます
  - 特定IP指定時はそのIPで内蔵画面を開きます
- パッケージ版でPDFサムネイルのCMap・フォントが読み込めない問題を修正

## LAN公開の設定

待ち受けホストには `0.0.0.0` を指定することを推奨します。特定のIPを指定する場合は、
そのIPがPCに割り当てられている必要があります。

## 未署名について

このリリースは**コード署名されていません**。Windows SmartScreen が
「Windows によって PC が保護されました」と表示する場合があります。

SHA-256 が `SHA256SUMS.txt` と一致することを確認したうえで、
**詳細情報 > 実行** を選択してください。

```powershell
Get-FileHash .\Kurarium-Installer-0.2.1-win-x64.exe -Algorithm SHA256
```

## データについて

既存のライブラリ設定・視聴履歴・サムネイルはそのまま引き継がれます。
0.2.0から更新した場合も、データの再設定は不要です。

- インストール版: `%LOCALAPPDATA%\Kurarium\data`
- ポータブル版: 展開先の `data`

## 既知の制限

- コード署名は未対応です。
- 自動更新はありません。
- LAN公開はHTTPです。信頼できるネットワークでのみ使用してください。
- Windows 10 22H2実機での検証は未実施です(Windows 11で検証)。
