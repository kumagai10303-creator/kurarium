# Kurarium 0.2.0

Windows 10 22H2 / Windows 11 (x64) 向けのアップデートです。

## ダウンロード

- `Kurarium-Installer-0.2.0-win-x64.exe`: インストーラ(管理者権限不要)
- `Kurarium-Portable-0.2.0-win-x64.zip`: ポータブル版
- `SHA256SUMS.txt`: SHA-256 チェックサム
- `LEGAL-NOTICES.zip`: ライセンス全文、第三者表記、FFmpegのソース情報

## 主な変更

- サムネイル作成中の進捗バーを追加(件数・割合・失敗数)
- サムネイルを最大384px / WebP品質75に縮小し、既存分は自動再生成
- サムネイル生成の並列数を見直し、キュー用インデックスを追加
- 孤立したサムネイルを自動削除
- 一覧・カード・履歴の再描画を抑制し、画像の遅延デコードを追加
- システム設定の「アプリ名」欄を廃止し、最上部に概要・バージョン表示を追加
- メディア種別の混在設定を保存ボタンなしで即時反映
- ウィンドウを閉じてトレイに格納した際、内蔵ブラウザを終了してメモリを解放
- トレイまたは二重起動から再度開くと内蔵ブラウザを再生成

## 未署名について

このリリースは**コード署名されていません**。Windows SmartScreen が
「Windows によって PC が保護されました」と表示する場合があります。

SHA-256 が `SHA256SUMS.txt` と一致することを確認したうえで、
**詳細情報 > 実行** を選択してください。

```powershell
Get-FileHash .\Kurarium-Installer-0.2.0-win-x64.exe -Algorithm SHA256
```

## データについて

既存のサムネイルは初回起動時に自動で再生成されます。生成中は画面上部に進捗が
表示されます。ライブラリの設定や視聴履歴はそのまま引き継がれます。

- インストール版: `%LOCALAPPDATA%\Kurarium\data`
- ポータブル版: 展開先の `data`

## 既知の制限

- コード署名は未対応です。
- 自動更新はありません。
- LAN公開はHTTPです。信頼できるネットワークでのみ使用してください。
- Windows 10 22H2実機での検証は未実施です(Windows 11で検証)。
