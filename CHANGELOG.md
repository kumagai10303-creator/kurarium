# Changelog

## 0.5.1

- Allow every library to be deleted, disabled, and enabled, including libraries created from legacy configuration.
- Fixed newly added libraries being treated as default and becoming impossible to delete.
- Changed the Settings tab field to a combobox that accepts free-form input while always offering all standard tabs.

## 0.5.0

- Windows 11 (x64) is the supported platform; Windows 10 is out of scope.
- Added HTTPS-only LAN publishing with a per-installation self-signed certificate.
- Added certificate download, fingerprint, expiry, address-coverage warnings, and regeneration in Settings.
- The Electron window trusts only the exact certificate generated by its local server.
- Added Host and Origin validation, cross-site API blocking, CSP, and stricter request body handling.
- Changed the LAN login password minimum to 5 characters and added a security recommendation for longer passwords.
- Marked LAN session cookies Secure and invalidated sessions when credentials change.
- Added request body limits and removed the permissive text/plain request parser.
- Added Explorer folder pickers to local library path fields in setup and Settings.
- Redesigned folder navigation as a sticky shelf with a section header, folder count, one-row/all-folders switch, a fluid expanded grid that fills the available width while preserving the configured tile shape, and clear separation from the file grid.
- Record image views in browsing history, and hide the History tab and entries while the history setting is off.
- Ask on uninstall whether to delete user data, defaulting to deletion.
- Changed the default folder tile shape to fixed 1:1 (square).
- Added OSS security, privacy, contribution, support, and code of conduct documents.
- Added release SBOM generation, build provenance attestation, and corresponding FFmpeg source packaging.
- Added CodeQL and Dependabot configuration.
- Added backend tests for request security and LAN certificate lifecycle.

## 0.4.0

- Generate thumbnails on demand for items near the visible area instead of pre-generating the whole library.
- Added a bounded thumbnail cache with a 512 MB default limit and least-recently-used eviction.
- Added an optional thumbnail retention period (TTL), disabled by default, in Settings > System.
- Added cache usage, limit, and TTL controls; changing the limit applies cleanup immediately.
- Added access timestamps and byte-size tracking to `thumbs.db` for LRU/TTL cleanup.
- Removed the full-library thumbnail queue and progress bar.
- Use measured thumbnail aspect ratios to reduce gallery layout gaps and jumps.
- Reduced thumbnail cache size automatically after upgrading; original media is unaffected.
- Fixed packaged Japanese PDF thumbnails by loading PDF.js CMaps from filesystem paths.
- Added per-IP login rate limiting and security response headers for LAN access.
- Register SMB credentials without passing the password on a process command line.
- Added Playwright smoke tests for the gallery, lightbox, and cache settings.
- Show each folder's first item by filename as its thumbnail, even before the thumbnail is generated.
- Fixed intermittent blank thumbnails after returning to the gallery by not resetting loaded state on mount.
- Retry thumbnail loads that were previously marked as failed.
- Improved first-launch Windows taskbar icon initialization.
- Added a LAN publishing toggle; the port field is editable only when enabled.
- Fall back to loopback when a saved LAN bind address is unavailable.

## 0.3.0

- Moved thumbnails from individual files into a single SQLite `thumbs.db`.
- Reduced thumbnail file count from tens of thousands to one database file.
- Changed thumbnails to height-based 360px / max width 1600px, WebP quality 76.
- Improved video thumbnails with height-based Lanczos scaling and quality 82.
- Added light sharpening for high-resolution image thumbnails.
- Added legacy file fallback while migrating existing thumbnails into the database.
- Added SQLite prepared statements, WAL, orphan cleanup, and incremental vacuum.
- Added thumbnail ETag/cache versioning to avoid stale images after regeneration.
- Added a pre-save SMB connection test using NTLMv2; failed credentials are not stored or used.
- Refreshed folder counts automatically when a scan completes.
- Moved thumbnail progress tracking in-memory and reduced Sharp concurrency to avoid UI stutter.
- Added thumbnail retry while generation is in progress and fixed square lightbox display for unknown dimensions.
- Fixed the previous image briefly using the next image's aspect ratio during lightbox navigation.
- Removed the horizontal resize cursor from lightbox navigation arrows.

## 0.2.1

- Fixed the embedded window failing to connect when a specific LAN IP was configured.
- Fixed PDF thumbnails failing to load CMaps and fonts from the packaged application.

## 0.2.0

- Added a thumbnail generation progress bar with completed/total counts and failures.
- Reduced thumbnail resolution and quality, with automatic background regeneration.
- Added orphaned thumbnail cleanup.
- Optimized thumbnail queue concurrency by media type and added a queue index.
- Reduced UI re-renders by memoizing gallery views and isolating scan status updates.
- Added lazy asynchronous image decoding and content-visibility for gallery rows.
- Replaced the app-name setting with an overview panel showing version and data folder.
- Made the mixed-media setting apply immediately without a save button.
- Destroyed the embedded browser when minimizing to the tray, recreating it on reopen.
- Renamed release assets to `Kurarium-Installer-*` and `Kurarium-Portable-*`.

## 0.1.0

- Initial Windows release.
- Per-user installer and portable ZIP.
- Electron tray application with embedded web UI.
- Local, SMB, PDF, music, and video libraries.
- Startup scan, thumbnails, and video transcoding.
- LAN access with session login.
