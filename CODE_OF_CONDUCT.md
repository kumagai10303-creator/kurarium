# Code of Conduct

## Our commitment

We want participation in Kurarium to be a respectful experience for everyone,
regardless of experience level, background, identity, or language.

## Expected behavior

- Be considerate and constructive.
- Assume good intent and ask clarifying questions.
- Give technical feedback about the work, not the person.
- Respect privacy: do not publish another person's paths, credentials, or media.
- Follow the security reporting process in [SECURITY.md](SECURITY.md) instead of
  posting vulnerability details publicly.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Deliberately disruptive or bad-faith contributions.
- Encouraging others to bypass security warnings or expose a LAN server to the
  internet.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, or restrict
participation when behavior violates this policy. Enforcement decisions should be
proportional and focused on keeping the project usable and safe.

## Scope

This policy applies in repository issues, pull requests, discussions, reviews, and
other project spaces.
