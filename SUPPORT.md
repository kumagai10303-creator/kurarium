# Support

Kurarium is maintained on a best-effort basis. There is no guaranteed response time
or commercial support.

## Before opening an issue

- Check the README and [docs](docs).
- Confirm you are using the latest release.
- Try the portable build if the installer fails.
- For LAN problems, confirm the certificate is trusted and the client and PC are on
  the same trusted network.

## What to include

- Kurarium version
- Windows version and architecture
- installer or portable build
- whether LAN publishing was enabled
- steps to reproduce
- error messages and relevant log excerpts with secrets and personal paths removed

Use GitHub Issues for bugs and feature requests. Report security issues through the
private process in [SECURITY.md](SECURITY.md).
